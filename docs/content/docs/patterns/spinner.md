Use `class="spinner"` on an SVG with an accessible label. Place it in an
`output` when status semantics are needed.

```html
<svg aria-label="Loading" viewBox="0 0 24 24" class="spinner">
  <circle cx="12" cy="12" r="10" />
</svg>
```
